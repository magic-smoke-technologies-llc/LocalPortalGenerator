# Local Portal Generator

An Abiotic Factor mod. Build a **Local Portal Generator** at your base, carry a **Portal Anchor** to a portal world and use it there, then open the game's own portal to that world from home whenever you like.

## mod.io

| | |
|---|---|
| Mod ID | **6510487** |
| Game ID | 13105 (Abiotic Factor) |
| Visibility | Private |

The same ID is stored in `PortalGeneratorPeO4A/PortalGeneratorPeO4A.abfmod`, which the editor reads when updating the listing, and in `modio.json`.

## Using it

1. Craft a Local Portal Generator (Travel category, Office tier) and place it with power.
2. Craft Portal Anchors. Use one inside each portal world you want to reach.
3. Tap F on the Generator's terminal to cycle through anchored worlds; the portal opens over the pad. Walk in.
